## Расположение файла

Корневой каталог данных совпадает с папкой программы, если выполняется любое из первых трёх условий таблицы. Иначе используется папка пользователя:

| Ситуация | Каталог |
|---|---|
| `portable.flag` лежит рядом с исполняемым файлом | Папка программы |
| `config.toml` лежит рядом с исполняемым файлом (Windows: только если эта папка доступна для записи) | Папка программы |
| Папка программы доступна для записи и не находится внутри приложения macOS в формате `.app` | Папка программы |
| Иначе, macOS | `~/Library/Application Support/Bardwave` |
| Иначе, Windows | `%APPDATA%\Bardwave` |
| Иначе, Linux и другие Unix-системы | `$XDG_DATA_HOME/bardwave` или `~/.local/share/bardwave` |

Если папку пользователя не удаётся определить (нет `HOME`, `USERPROFILE` или `APPDATA`) или создать её, используется папка программы. Пустые переменные окружения считаются незаданными.

**Портативный режим:** создайте пустой файл с именем `portable.flag` рядом с исполняемым файлом. Проверяется только наличие файла. Установки в Windows и Linux не проверялись **(не проверено)**.

При `--profile <name>` файлы размещаются так:

| Путь (в корневом каталоге) | Содержимое |
|---|---|
| `config.toml`, `bardwave-library/` | Профиль по умолчанию |
| `profiles/<name>/config.toml`, `profiles/<name>/bardwave-library/` | Именованный профиль |
| `bardwave.log`, `tools/`, `recent.toml` | Общие для всех профилей |

Записи сохраняются в `recordings/`, а самоподписанные сертификаты HTTPS — в `tls/`; оба каталога находятся в каталоге данных профиля. `bardwave-library/` хранит аудио, загруженное Bardwave; `tools/` — вспомогательные инструменты, которые программа загрузила. Папка именованного профиля создаётся при первом использовании.

Имя профиля обрезается по краям от пробелов и содержит 1–32 символа: буквы, цифры, пробелы, `-`, `_`. Имя `default` (в любом регистре) означает профиль по умолчанию и не принимается для обычного профиля. Зарезервированные имена устройств Windows (`CON`, `PRN`, `AUX`, `NUL`, `COM1`–`COM9`, `LPT1`–`LPT9`) не принимаются. Переключение профилей в консоли перезапускает Bardwave с другим профилем.

## Формат файла и миграция

Файл `config.toml` — это TOML. Все параметры необязательны. Отсутствующий параметр получает значение по умолчанию, указанное ниже. Целочисленные параметры беззнаковые: отрицательное или слишком большое число (например, `port = 70000`) вызывает ошибку разбора.

- Если файла нет, применяются все значения по умолчанию. Файл создаётся при первом запуске.
- Неизвестные параметры при загрузке пропускаются, а при сохранении удаляются.
- Файл, который не удаётся разобрать (или прочитать), останавливает запуск с кодом выхода 1. В диалоге выводится `config.toml could not be read`; при `--server-only` диалога нет, и ошибка выводится в stderr. Возврата к значениям по умолчанию нет.

> **Предупреждение:** Bardwave переписывает `config.toml` с собственным форматированием при каждом сохранении, в том числе при первом запуске (тогда сохраняется ключ доступа) и при изменениях библиотеки. Комментарии теряются, в том числе комментарии в поставляемом примере файла. Большинство параметров записываются полностью, даже если их значение совпадает со значением по умолчанию. Необязательные параметры и пустые списки, если они не заданы, не записываются: `output_device`, `preview_device`, `recordings_dir`, `tls_cert`, `tls_key`, `tags`, `pan = 0`, `ui_scale = 1.0`, `record_float32 = false`, `last_update_check = 0`, `onboarding_done = false`, а также пустые `[[hotkeys]]`, `[[timers]]`, сцены и плейлисты. Встроенные таблицы, такие как `action = { ... }` и `trigger = { ... }`, при сохранении превращаются в таблицы `[hotkeys.action]` и `[timers.trigger]` (с тем же смыслом). Значения типа float могут получить дополнительные цифры (`0.8` сохраняется как `0.800000011920929`). Сохраните копию файла, написанного вручную.

Миграция данных старых версий:

- Звуки, сцены и плейлисты без `id` получают UUID при загрузке и сохраняют его при следующем сохранении. Так обновляются конфигурации версии v1.4.0, в которых не было id.
- Записанные вручную идентификаторы, например `"rain"`, превращаются в UUID. Ссылки в элементах сцен, эмиттерах (источниках случайных звуков), поле `playlist` сцены, поле `items` плейлиста и в `[[hotkeys]]` переписываются в соответствии с ними. Ссылки в `[[timers]]` не переписываются: в них используйте UUID.
- Повторяющийся идентификатор получает новый UUID. Первый владелец сохраняет свой идентификатор.
- Отсутствующий `access_token` или `gm_token` генерируется и сохраняется при запуске.
- Отсутствующие разделы и параметры старых конфигураций (`[gui]`, `[library]`, `output_device`, `tls` и так далее) получают значения по умолчанию, поэтому старый файл продолжает работать без изменений. Конфигурация, в которой уже есть звуки, при первом запуске консоли получает отметку `onboarding_done = true`.
- Существующие установки сохраняют данные на прежнем месте: `config.toml` рядом с исполняемым файлом сохраняет папку программы как каталог данных (см. [Расположение файла](#file-location)). Ничего не перемещается.

<a id="command-line-flags"></a>

## Флаги командной строки

Прочие аргументы игнорируются. Флагов `--help` и `--version` нет.

| Флаг | Действие |
|---|---|
| `--server-only` | Запускается без окна. Загружает сохранённую библиотеку, запускает сервер для слушателей и записывает в журнал ссылку для слушателей и ссылку на страницу управления (при уровне `info` по умолчанию). Остановка: Ctrl+C. `[[hotkeys]]` и `[[timers]]` в этом режиме не выполняются. Измерения громкости, выполняемые в фоне (`normalize`), сохраняются в `config.toml`. |
| `--profile <name>` | Использует указанный профиль. Вариант `--profile=<name>` тоже работает. `default` означает профиль по умолчанию. Если флаг указан несколько раз, действует последнее значение. |

Если `--profile` указан без значения или с недопустимым именем, выводится `Error: ...`, и программа завершается с кодом 2. То же происходит, если не удаётся создать папку профиля. Без `--server-only` сообщение также показывается в диалоге.

```bash
./bardwave --server-only
./bardwave --server-only --profile "Camp 1"
```

При `--server-only` в журнале ссылка удалённого управления показывается как `/control?g=<gm_token from config.toml>`. Сам ключ в журнал не записывается.

## Переменные окружения

| Переменная | Действие |
|---|---|
| `RUST_LOG` | Если задан корректный фильтр, он заменяет `[logging] level`. Используется синтаксис фильтров `tracing`. Если переменная не задана или её значение некорректно, используется `[logging] level`. |
| `SOUNDSHARED_REDUCED_MOTION` | `1`, `true`, `yes`, `on` отключают декоративную анимацию; `0`, `false`, `no`, `off` её включают. Регистр не учитывается. Прочие значения (в том числе пустое) игнорируются. Переопределяет `[gui] reduce_motion` на время одного запуска программы. |
| `HOME`, `USERPROFILE`, `APPDATA`, `XDG_DATA_HOME` | Используются только для выбора каталога данных пользователя. |

<a id="server"></a>

## \[server\]

| Параметр | Тип | По умолчанию | Допустимые значения | Действие |
|---|---|---|---|---|
| `port` | целое число | `8080` | 1–65535 | Порт для HTTP и WebSocket. Консоль не принимает 0. Значение `0` в файле не проверяется **(не проверено)**. |
| `host` | строка | `"0.0.0.0"` | IP-адрес | Адрес привязки. `0.0.0.0` означает все интерфейсы IPv4. Консоль принимает только IP-адреса в виде литералов. Значение в файле, которое не является IP-адресом, при запуске заменяется на `0.0.0.0`. |
| `upnp` | логическое значение | `true` | | Просит роутер (UPnP IGD) выполнить проброс порта. |
| `access_token` | строка | генерируется | любое значение; `""` = открытый доступ | Ключ доступа, входящий в ссылку для слушателей `/?k=<key>`. Если отсутствует, генерируется и сохраняется при запуске: 16 символов `a-z` и `0-9`. |
| `gm_token` | строка | генерируется | любое значение; `""` = только локально | Токен ведущего (game master, GM), входящий в адрес страницы управления `/control?g=<key>`. Генерируется, если отсутствует. `""` оставляет страницу только на этом компьютере. |
| `tls` | логическое значение | `false` | | HTTPS и `wss://` на том же порту. Применяется при следующем запуске. |
| `tls_cert` | строка (путь) | нет | цепочка PEM | Ваш сертификат. Задаётся вместе с `tls_key` или не задаётся вовсе (тогда самоподписанный сертификат создаётся в `tls/`). Пустая строка считается незаданной. |
| `tls_key` | строка (путь) | нет | ключ PEM | Закрытый ключ для `tls_cert`. |

В консоли параметры `port` (PORT) и `host` (BIND ADDRESS) в блоке CONFIGURATION можно менять только при остановленном сервере. Ключ доступа отображается как ACCESS KEY на панели SERVER, а токен ведущего — под «GM panel link» (кнопки **Create GM key** (создать токен ведущего), **New key** (новый ключ), **Replace key** (заменить ключ)).

При `tls = true` указание только одного из параметров `tls_cert` и `tls_key` приводит к ошибке запуска `tls_cert and tls_key must be set together`; сервер не запускается.

> **Предупреждение:** `access_token = ""` позволяет слушать трансляцию любому, кто может обратиться к порту. Используйте это только в доверенной сети.

> **Примечание:** `gm_token` генерируется по умолчанию, поэтому удалённое управление включено. Любой, у кого есть ссылка с `?g=`, может нажимать кнопки ведущего. Чтобы страница оставалась только локальной, задайте `gm_token = ""`.

## \[audio\]

| Параметр | Тип | По умолчанию | Допустимые значения | Действие |
|---|---|---|---|---|
| `buffer_size` | целое число | `960` | `0` или 64–8192 | Буфер звуковой карты в кадрах. 960 — это 20 ms при 48 kHz. `0` — значение драйвера по умолчанию. Другие значения выводят предупреждение и используют 480 (10 ms). |
| `sample_rate` | целое число | `48000` | 8000–192000 | Частота дискретизации, запрашиваемая у карты. Аудиопоток (stream) для игроков всегда идёт на 48 kHz. Значение вне диапазона выводит предупреждение, и используется 48000. |
| `channels` | целое число | `2` | 1–8 | Каналы звуковой карты. 1 — сведение в моно, больше 2 добавляет микс по центру на дополнительные каналы. Значение вне диапазона выводит предупреждение, и используется 2. |
| `master_volume` | вещественное число | `0.8` | 0.0–1.0 | Общая громкость при запуске. **Значение вне этого диапазона останавливает запуск с ошибкой** (без диалога; ошибка выводится в stderr). |
| `normalize` | логическое значение | `false` | | Измеряет громкость (EBU R128) звуков, у которых `gain_db` равен `0.0`, и записывает поправку в `gain_db`. Звуки, читаемые с диска потоком, не измеряются. В консоли: **NORMALIZE LOUDNESS** (нормализация громкости). |
| `normalize_target_lufs` | вещественное число | `-18.0` | используется в пределах от -60 до 0 | Цель нормализации громкости (normalization). Поле консоли **Target** (целевая громкость) предлагает значения от -36 до -8 LUFS. Значение, не являющееся числом, заменяется на -18. |
| `duck_amount` | вещественное число | `0.3` | используется в пределах 0.0–1.0 | Линейный уровень шин (bus) при приглушении (ducking). `0.3` — примерно -10 dB. `1.0` отключает приглушение, `0.0` полностью выключает звук приглушаемых шин. В консоли: **Duck settings** (настройки приглушения), **Level** (уровень). |
| `duck_attack_ms` | целое число | `200` | миллисекунды | Время затухания при приглушении. В консоли допускается от 0 до 10000. |
| `duck_release_ms` | целое число | `800` | миллисекунды | Время нарастания громкости после приглушения. В консоли допускается от 0 до 30000. |
| `duck_buses` | массив строк | `["music", "ambience"]` | `music`, `ambience`, `sfx` | Шины, громкость которых снижается при приглушении. В консоли: флажки **Ducks**. |
| `stream_threshold_secs` | целое число | `60` | секунды; `0` — выключено | Файлы длиннее этого значения читаются с диска во время воспроизведения. |
| `output_device` | строка | нет | имя устройства | Вывод звука на этот компьютер. Если устройство отсутствует, используется системное устройство по умолчанию, и консоль сообщает об этом. В консоли: **AUDIO OUTPUT** (вывод звука), **Output** (основной вывод). |
| `preview_device` | строка | нет | имя устройства | Устройство только для предпрослушивания (preview). Если не задано, используется основной вывод. Предпрослушивание никогда не попадает к игрокам. В консоли: **Preview**. |

Раздел **AUDIO OUTPUT** применяет смену устройства сразу и сохраняет её. Размер буфера, частота дискретизации и количество каналов показываются там только для чтения. Пустое имя устройства считается незаданным.

<a id="hotkeys"></a>

## \[\[hotkeys\]\]

Привязки находятся на верхнем уровне файла, а не в `[library]`. Они используются только окном консоли.

- `key` (обязательный): клавиши-модификаторы и одна клавиша, соединённые через `+`, например `Ctrl+Shift+A` или `F9`. Модификаторы: `Ctrl`, `Alt`, `Shift`, `Cmd` (Command в macOS или клавиша Windows / Super), с синонимами `Control`, `Option`/`Opt`, `Command`/`Super`/`Meta`/`Win`. `CmdOrCtrl` означает `Cmd` в macOS и `Ctrl` в остальных системах. Клавиши: буквы, цифры, `F1`–`F24`, `Numpad0`–`Numpad9`, `Space`, `Enter`, `Escape`, `Tab`, `Backspace`, стрелки (`Up`, `Down`, `Left`, `Right`) и другие именованные клавиши. Регистр и порядок не имеют значения.
- `action` (обязательный): встроенная таблица с `kind` и, для первых трёх видов, `target`.

| `kind` | `target` | Подпись в консоли | Действие |
|---|---|---|---|
| `sound` | идентификатор звука | Play sound / stinger (воспроизвести звук / стингер) | Воспроизводит. Стингеры проигрываются один раз, остальные звуки переключают воспроизведение. |
| `scene` | идентификатор сцены | Activate scene (активировать сцену) | Активирует сцену. |
| `playlist` | идентификатор плейлиста | Start playlist (запустить плейлист) | Запускает или перезапускает плейлист. |
| `stop_all` | нет | Stop all (остановить всё) | Останавливает всё. |
| `stop_scene` | нет | Stop scene (остановить сцену) | Останавливает активную сцену. |
| `master_up` | нет | Master volume up (увеличить общую громкость) | Один шаг (0.05) вверх. |
| `master_down` | нет | Master volume down (уменьшить общую громкость) | Один шаг (0.05) вниз. |
| `master_mute` | нет | Master mute (выключить общий звук) | Выключает или включает звук. |
| `duck_toggle` | нет | Duck background (toggle) (приглушить фон, переключатель) | Приглушает при одном нажатии, снимает приглушение при следующем. |
| `duck_hold` | нет | Duck background (hold) (приглушить фон, удержание) | Приглушает, пока клавиша удерживается. |
| `next_track` | нет | Next track (следующий трек) | Следующий трек плейлиста. |
| `prev_track` | нет | Previous track (предыдущий трек) | Предыдущий трек плейлиста. |
| `pause_music` | нет | Pause / resume music (пауза / продолжить музыку) | Ставит музыку на паузу или возобновляет её. |

> **Примечание:** Некорректные привязки сохраняются и сообщаются, но не удаляются. Если две записи имеют одинаковую клавишу, срабатывает первая, а вторая никогда не срабатывает. Клавиши MIDI (`Midi:...`) в этой сборке никогда не срабатывают, см. [Сцены, музыка, горячие клавиши и таймеры](./scenes-music-hotkeys.md).

<a id="timers"></a>

## \[\[timers\]\]

Таймеры — это таймеры сессии. Сохраняются только описания. Они всегда запускаются остановленными и работают только при открытой консоли Bardwave (не при `--server-only`). В консоли: кнопка **Timers** (таймеры), а также **Start** (запуск), **Pause timers** (пауза таймеров), **Reset** и **New timer** (новый таймер).

| Параметр | Тип | По умолчанию | Действие |
|---|---|---|---|
| `id` | строка | `""` | Уникальный идентификатор. Консоль создаёт UUID; для вручную написанного таймера задайте каждому свой, так как обратный отсчёт сопоставляется по id. |
| `name` | строка | `""` | Имя в диалоге «Timers» (в консоли до 60 символов). |
| `trigger` | встроенная таблица | `{ after_ms = 600000 }` | `after_ms = N` срабатывает один раз через N ms после запуска. `every_ms = N` повторяется. Интервалы короче 100 ms не могут работать. Консоль редактирует его в минутах (0–999) и секундах. |
| `action` | встроенная таблица | `{ kind = "stop_all", fade_ms = 2000 }` | Что происходит (см. ниже). |
| `enabled` | логическое значение | `true` | `false` оставляет таймер невзведённым. |

Таймер с условием срабатывания короче 100 ms или с пустой целью никогда не срабатывает.

| `kind` | Поля | Подпись в консоли | Действие |
|---|---|---|---|
| `activate_scene` | `scene` | Activate scene | Переключает на сцену. |
| `stop_scene` | нет | Stop scene | Выполняет затухание активной сцены. |
| `play_stinger` | `sound` | Play stinger (воспроизвести стингер) | Проигрывает звук один раз поверх всего. |
| `stop_all` | `fade_ms` | Stop all (fade out) | Выполняет затухание всего. Если `fade_ms` в файле не указан, означает `0`. В консоли предлагаются значения от 0 до 120 s. |
| `start_playlist` | `playlist` | Start playlist | Запускает или перезапускает плейлист. |
| `stop_playlist` | нет | Stop music (остановить музыку) | Выполняет затухание и останавливает музыку. |
| `next_track` | нет | Next track | Следующий трек плейлиста. |
| `pause_music` | нет | Pause music (пауза музыки) | Ставит музыку на паузу. |
| `resume_music` | нет | Resume music (продолжить музыку) | Продолжает воспроизведение музыки. |

<a id="library"></a>

## \[library\]

У звуков, сцен и плейлистов есть `id` в формате UUID, а ссылки используют идентификаторы, но никогда не пути. Консоль ограничивает `volume` диапазоном 0.0–1.0, `pan` — диапазоном -1.0–1.0, а `gain_db` — диапазоном -48.0–24.0. При загрузке `pan`, `gain_db`, `volume` элементов сцены и уровни эмиттеров приводятся к этим диапазонам (значение, не являющееся числом, становится 0). Собственный `volume` звука при загрузке не ограничивается.

Правила исправления при загрузке библиотеки:

- Группа пропускается, если её `id` не является UUID или повторяет предыдущий, либо если её `name` после обрезки пробелов пустое или длиннее 32 символов.
- Звук пропускается, если его `path` пустой или повторяет путь предыдущего звука. `group`, которой не существует, делает звук без группы.
- Элементы сцен, звуки эмиттеров и треки плейлистов, у которых id не является UUID, отбрасываются. UUID, которому ничего не соответствует, сохраняется и выводится как предупреждение.
- `color` сцены, который не является `#rgb` или `#rrggbb`, отбрасывается. `playlist` сцены, который не является UUID, отбрасывается.
- Имена сцен и плейлистов в консоли ограничены 64 символами и там уникальны без учёта регистра.

### \[\[library.groups\]\]

| Параметр | Тип | По умолчанию | Действие |
|---|---|---|---|
| `id` | строка | обязательный | UUID группы. |
| `name` | строка | обязательный | Имя группы, 1–32 символа, уникальное без учёта регистра при создании в консоли. |

### \[\[library.sounds\]\]

| Параметр | Тип | По умолчанию | Действие |
|---|---|---|---|
| `id` | строка | генерируется | UUID звука. |
| `path` | строка | обязательный | Путь к аудиофайлу. |
| `name` | строка | `""` | Отображаемое имя. Если пусто, показывается имя файла. |
| `volume` | вещественное число | `1.0` | Уровень, 0.0–1.0. |
| `looped` | логическое значение | `false` | Перезапускается по окончании. |
| `group` | строка | нет | Идентификатор группы. |
| `tags` | массив строк | `[]` | Пробелы по краям обрезаются, строчные буквы, до 32 символов каждый, без дубликатов. Не записывается, если список пуст. |
| `gain_db` | вещественное число | `0.0` | Фиксированная поправка в dB поверх `volume`. |
| `bus` | строка | `"ambience"` | `music`, `ambience`, `sfx`. |
| `oneshot_stinger` | логическое значение | `false` | Проигрывается один раз поверх всего, не останавливая остальные звуки. |
| `pan` | вещественное число | `0.0` | От -1.0 (слева) до 1.0 (справа). Записывается, только если значение не 0. |

### \[\[library.scenes\]\]

| Параметр | Тип | По умолчанию | Действие |
|---|---|---|---|
| `id` | строка | генерируется | UUID сцены. |
| `name` | строка | `""` | Надпись на кнопке. |
| `color` | строка | нет | `#rrggbb` или `#rgb`. Если не задано, используется тема оформления. |
| `fade_in_ms` | целое число | `2000` | Нарастание громкости звуков сцены. В консоли предлагаются значения от 0 до 60000. |
| `fade_out_ms` | целое число | `2000` | Затухание звуков, которые сцена останавливает. В консоли предлагаются значения от 0 до 60000. |
| `curve` | строка | `"equal_power"` | `equal_power` или `linear`. |
| `stop_others` | логическое значение | `true` | Затухают звуки, не входящие в сцену. |
| `playlist` | строка | нет | Идентификатор плейлиста, который воспроизводится как слой музыки. |

### \[\[library.scenes.items\]\]

| Параметр | Тип | По умолчанию | Действие |
|---|---|---|---|
| `sound` | строка | обязательный | Идентификатор звука. |
| `volume` | вещественное число | `1.0` | Уровень внутри этой сцены, 0.0–1.0 (заменяет собственную громкость звука). |
| `looped` | логическое значение | `false` | Повторяется, пока сцена активна. |
| `start` | строка | `"on_enter"` | `on_enter` или `manual`. |
| `delay_ms` | целое число | `0` | Задержка после активации. В консоли предлагаются значения от 0 до 600000. |
| `pan` | вещественное число | `0.0` | Ненулевое значение заменяет панораму (pan) звука. Записывается, только если значение не 0. |

### \[\[library.scenes.emitters\]\]

| Параметр | Тип | По умолчанию | Действие |
|---|---|---|---|
| `sounds` | массив строк | `[]` | Возможные идентификаторы звуков. Повторы удаляются. |
| `min_interval_ms` | целое число | `20000` | Самая короткая пауза. Фактический минимум 100 ms. |
| `max_interval_ms` | целое число | `60000` | Самая длинная пауза. Меняется местами с минимумом, если она меньше. В консоли для обоих параметров предлагаются значения от 100 ms до 1 часа. |
| `volume` | вещественное число | `1.0` | Базовый уровень, 0.0–1.0. |
| `volume_jitter` | вещественное число | `0.0` | Случайный разброс громкости, 0.0–1.0. |
| `pan_jitter` | вещественное число | `0.0` | Случайный разброс панорамы по стерео, 0.0–1.0. |
| `max_overlap` | целое число | `2` | Максимум одновременных экземпляров. Фактический минимум 1. В консоли предлагаются значения до 16. |

### \[\[library.playlists\]\]

| Параметр | Тип | По умолчанию | Действие |
|---|---|---|---|
| `id` | строка | генерируется | UUID плейлиста. |
| `name` | строка | `""` | Отображаемое имя. |
| `items` | массив строк | `[]` | Идентификаторы звуков в порядке воспроизведения. |
| `shuffle` | логическое значение | `false` | Случайный порядок, без повторов, пока не сыграют все. |
| `repeat` | строка | `"all"` | `off`, `all`, `one`. |
| `crossfade_ms` | целое число | `2000` | `0` — прямая склейка без перехода. В консоли предлагаются значения от 0 до 30000. |
| `bus` | строка | `"music"` | `music`, `ambience`, `sfx`. |

Сцены, плейлисты, элементы сцен и эмиттеры не записываются, если список пуст.

<a id="complete-example"></a>

## Полный пример

Этот файл является корректным TOML и охватывает все разделы. UUID здесь примерные. Замените их или удалите строки `id`, и Bardwave сгенерирует их сам (кроме таймеров: им нужен собственный `id`). Каждая ссылка должна соответствовать `id` в файле.

```toml
# config.toml: annotated example. Omitted keys use the defaults above.

[server]
host = "0.0.0.0"
port = 8080
upnp = true
# access_token = "k3j9x0a7p2m5q8w1"   # generated at start when missing; "" = anyone can listen
# gm_token = "t4n8v2c6b0z3y7u5"       # generated at start when missing; "" = control page on this PC only
tls = false                 # HTTPS and wss://, applied on next Start
# tls_cert = "/etc/ssl/bardwave/fullchain.pem"   # set together with tls_key, or neither
# tls_key = "/etc/ssl/bardwave/privkey.pem"

[audio]
buffer_size = 960           # frames; 0 = driver default
sample_rate = 48000
channels = 2
master_volume = 0.8         # must be 0.0 to 1.0
normalize = false
normalize_target_lufs = -18.0
duck_amount = 0.3
duck_attack_ms = 200
duck_release_ms = 800
duck_buses = ["music", "ambience"]
stream_threshold_secs = 60  # 0 turns streaming off
# output_device = "USB Headphones"
# preview_device = "Built-in Output"

[logging]
level = "info"              # trace | debug | info | warn | error
file_logging = false

[gui]
reduce_motion = false
global_hotkeys = false
# recordings_dir = "/Users/you/Recordings"
# record_float32 = false
check_updates = false
ui_scale = 1.0              # 0.8 to 1.6

[[hotkeys]]
key = "Ctrl+1"
action = { kind = "scene", target = "c3d4e5f6-a7b8-4c9d-8e0f-2a3b4c5d6e7f" }

[[hotkeys]]
key = "F9"
action = { kind = "stop_all" }

[[timers]]
id = "f6a7b8c9-d0e1-4f2a-8b3c-5d6e7f8091a2"
name = "Last call"
trigger = { after_ms = 3600000 }        # once, one hour after Start
action = { kind = "stop_all", fade_ms = 5000 }
enabled = true

[[library.groups]]
id = "a7b8c9d0-e1f2-4a3b-9c4d-6e7f8091a2b3"
name = "Tavern"

[[library.sounds]]
id = "a1b2c3d4-e5f6-4a7b-8c9d-0e1f2a3b4c5d"
path = "C:/Bardwave/sounds/tavern-chatter.ogg"
volume = 0.6
looped = true
group = "a7b8c9d0-e1f2-4a3b-9c4d-6e7f8091a2b3"
tags = ["tavern", "crowd"]

[[library.sounds]]
id = "b2c3d4e5-f6a7-4b8c-9d0e-1f2a3b4c5d6e"
path = "C:/Bardwave/sounds/thunder.wav"
bus = "sfx"
oneshot_stinger = true
pan = -0.2

[[library.sounds]]
id = "e5f6a7b8-c9d0-4e1f-8a2b-4c5d6e7f8091"
path = "C:/Bardwave/music/lute.mp3"
bus = "music"

[[library.scenes]]
id = "c3d4e5f6-a7b8-4c9d-8e0f-2a3b4c5d6e7f"
name = "Tavern"
color = "#a04a4a"
fade_in_ms = 2000
fade_out_ms = 2000
curve = "equal_power"
stop_others = true
playlist = "d4e5f6a7-b8c9-4d0e-9f1a-3b4c5d6e7f80"

[[library.scenes.items]]
sound = "a1b2c3d4-e5f6-4a7b-8c9d-0e1f2a3b4c5d"
volume = 0.4
looped = true
start = "on_enter"
delay_ms = 0

[[library.scenes.emitters]]
sounds = ["b2c3d4e5-f6a7-4b8c-9d0e-1f2a3b4c5d6e"]
min_interval_ms = 20000
max_interval_ms = 60000
volume = 0.7
volume_jitter = 0.1
pan_jitter = 0.5
max_overlap = 2

[[library.playlists]]
id = "d4e5f6a7-b8c9-4d0e-9f1a-3b4c5d6e7f80"
name = "Tavern music"
items = ["e5f6a7b8-c9d0-4e1f-8a2b-4c5d6e7f8091"]
shuffle = true
repeat = "all"
crossfade_ms = 2000
bus = "music"
```
