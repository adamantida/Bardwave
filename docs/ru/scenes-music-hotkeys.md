# Сцены, музыка и горячие клавиши

**Сцена** — это сохранённый микс звуков с их уровнями и затуханиями. **Плейлист** — это фоновая музыка. **Эмиттеры** (источники случайных звуков) воспроизводят случайные звуки, пока работает сцена. **Таймеры** позже запускают действия. **Горячие клавиши** запускают их с клавиатуры.

Эта страница написана по исходному коду и его модульным тестам. Поведение, не проверенное на реальном оборудовании, отмечено **(не проверено)**. Формат файла `config.toml` описан в [Справочнике по конфигурации](./configuration.md); про звуки, стингеры (stinger) и аудиоформаты см. [Звуковую библиотеку](./soundboard-library.md).

<a id="scenes"></a>
## Сцены

Сцена запускает набор звуков одним действием. При активации сцены звуки, которые в неё не входят, затухают, если только **Stop other sounds** (остановить другие звуки) не выключено (`stop_others = false`). В любом случае не затрагиваются: играющие стингеры, собственные звуки эмиттеров сцены, трек собственного плейлиста сцены и звук сцены, помеченный **Manual** (вручную).

Повторная активация уже активной сцены ничего не перезапускает. Звук сцены, который уже играет, лишь подстраивается под уровень и настройку зацикливания сцены, а отложенные запуски, которые ещё ждут, сохраняют своё время. Звук, который встречается в сцене дважды, учитывается один раз (побеждает первый элемент). Элементы, звук которых отсутствует в библиотеке, пропускаются и записываются в журнал.

### Сохранение текущего микса

1. Запустите звуки и задайте их уровни.
2. Нажмите **Save Mix As Scene** (сохранить микс как сцену) на панели **Scenes** (сцены) (на узких окнах — **Save Mix** (сохранить микс), на самых узких — только значок).
3. Введите название в поле **Scene name** (название сцены), до 64 символов.
4. Нажмите **Save Scene** (сохранить сцену).

Сцена сохраняет звуки, которые играют сейчас, с их текущими уровнями и настройками зацикливания. Стингеры не включаются. Каждый элемент запускается автоматически, без задержки и без переопределения панорамы (pan). Затухания — 2000 ms, кривая — equal power (равная мощность), а `stop_others` включено. Если ничего не играет, кнопка неактивна. Повторяющееся название (без учёта регистра) отклоняется с сообщением `A scene with this name already exists`.

### Панель и меню сцен

- В заголовке показаны количество сцен и активная сцена. **Hide** (скрыть) / **Show** (показать) сворачивает панель. **New** (создать) создаёт пустую сцену (открывает редактор).
- Щелчок по карточке сцены активирует её. На активной карточке написано `ACTIVE`, а пока идёт нарастание, — `ACTIVE · FADING IN n%`. Значок `!` на карточке перечисляет проблемы, например отсутствующий звук или файл. Карандаш на карточке открывает редактор.
- Щёлкните правой кнопкой по карточке, чтобы выбрать **Activate** (активировать), **Edit…** (изменить), **Duplicate** (дублировать) или **Delete…** (удалить). **Duplicate** копирует элементы, эмиттеры, музыку и затухания под названием `X copy`. **Delete…** запрашивает подтверждение (**Delete** / **Keep**: удалить / оставить), оставляет звуки в библиотеке и удаляет горячие клавиши, которые запускают сцену. Таймер, который ссылается на сцену, не удаляется: его строка показывает проблему, а при срабатывании он записывает предупреждение в журнал.
- Щёлкните правой кнопкой по звуку в списке звуков и выберите сцену в пункте **Add to scene** (добавить в сцену), чтобы добавить звук с сохранённым уровнем.

### Редактор сцены

| Поле | По умолчанию | Примечания |
| --- | --- | --- |
| Scene name | `Scene N` | До 64 символов, уникально без учёта регистра. |
| Button colour (цвет кнопки) | нет | Восемь готовых образцов, **None** (нет), или поле **Hex** (шестнадцатеричный код: `#rgb` / `#rrggbb`; `#` добавляется, если его нет). Тёмный цвет на карточке осветляется, чтобы оставаться видимым. |
| Fade in (ms), Fade out (ms) (нарастание / затухание, мс) | 2000 | От 0 до 60000. Принимает `2000`, `2000 ms`, `2.5 s`. |
| Curve (кривая) | Equal power | `Equal power` (постоянная суммарная мощность на протяжении кроссфейда (crossfade)) или `Linear` (линейная). |
| Stop other sounds: on / off | вкл. | Включает или выключает `stop_others`. |

Выбирайте звуки кнопкой **Add sound…** (добавить звук…). У каждого элемента есть ползунок уровня (уровень элемента заменяет собственную громкость звука внутри сцены), **Loop** (зацикливание), режим запуска: **Auto** (автоматически) или **Manual** (вручную), ползунок панорамы и поле задержки (по умолчанию `0`, до 600000 ms, принимается `1.5 s`), а также кнопка удаления. Новый элемент получает собственный уровень звука и его флаг зацикливания.

- **Auto** (`on_enter`) запускает элемент при активации сцены, после его задержки.
- **Manual** (`manual`) показывает элемент в списке, но запускает его, только когда вы запускаете его вручную, например из списка звуков. Его задержка игнорируется, а поле неактивно.
- Ползунок панорамы идёт от L 100 % до R 100 %; двойной щелчок возвращает его в центр. Ненулевая панорама элемента заменяет собственную панораму звука, пока эта сцена активна; центр означает собственную панораму звука.
- Отложенные запуски хранятся в Director и освобождаются на его такте (tick). Если вы покинете сцену до окончания задержки, запуск отменяется.

Эмиттеры и музыкальный плейлист сцены редактируются в отдельном диалоге (см. [Эмиттеры и музыка сцены](#emitters-and-scene-music)); сохранение редактора сцены их не меняет.

### Время перехода

В строке **Transition** (переход) есть переключатель **Auto** и ползунок от 0 до 10 s с шагом 100 ms, начальное значение — 2.0 s. При включённом **Auto** строка показывает `Per scene`, и каждая сцена использует собственные затухания. Перемещение ползунка выключает **Auto** и применяет это время как нарастание и затухание к карточкам сцен, **Stop Scene** (остановить сцену) и **Fade Out** (плавное затухание). Ползунок не сохраняется в `config.toml`, а сами сцены не меняются.

> **Примечание:** Горячие клавиши и таймеры игнорируют ползунок и используют собственные затухания каждой сцены. Это прочитано из кода и не запускалось.

### Стингеры

Стингер — это однократный звук, наложенный поверх всего. Он не останавливает другие звуки, и при смене сцены он не затрагивается, пока играет. Щёлкните правой кнопкой по звуку и выберите **Use As Stinger** (использовать как стингер) или **Remove Stinger Flag** (убрать отметку стингера). Для каждого стингера под сеткой сцен, в строке **Stingers** (стингеры), появляется пэд; он показывает название звука и проигрывает его один раз. Стингеры не входят в сохранённый микс. Стингер играет на шине звука (bus) с собственным уровнем звука. В `config.toml` флаг записывается как `oneshot_stinger = true`. Горячая клавиша для звука-стингера и действие таймера **Play stinger** (воспроизвести стингер) срабатывают одинаково.

<a id="stopping-sound"></a>
## Остановка звука

| Элемент | Что останавливает | Время затухания |
| --- | --- | --- |
| **STOP ALL** (остановить всё; командная панель, аварийная кнопка) | Всё сразу: звуки, сцена, музыка и предпрослушивание (preview) в наушниках. | Нет (только короткое плавное изменение громкости против щелчка). |
| **Stop Scene** (панель; неактивна без активной сцены) | Играющие звуки активной сцены, её эмиттеры и музыка, которую запустила сцена. Стингеры и другие звуки продолжают играть. | Ползунок, если **Auto** выключено, иначе `fade_out_ms` сцены. |
| **Fade Out** (панель) | Всё, включая стингеры, эмиттеры и музыку. Ожидающие отложенные запуски отменяются. | Ползунок, если **Auto** выключено; иначе `fade_out_ms` активной сцены, иначе 2000 ms. |
| Горячая клавиша `Stop scene` | То же, что **Stop Scene**. | Собственный `fade_out_ms` сцены (ползунок игнорируется). |
| Горячая клавиша `Stop all` | Всё. Предпрослушивание в наушниках тоже останавливается. | `fade_out_ms` активной сцены или 0 ms, если активной сцены нет. |
| Таймер `Stop all (fade out)` | Всё. Предпрослушивание в наушниках тоже останавливается. | `fade_ms` действия (целые секунды, от 0 до 120 в консоли). |

После **Fade Out**, **STOP ALL** или `Stop all` никакая сцена не остаётся активной. **Stop Scene** тоже оставляет без активной сцены.

<a id="emitters-and-scene-music"></a>
## Эмиттеры и музыка сцены

Откройте **Music…** (музыка…; на панели музыки внизу) и выберите вкладку **Scenes**. Нажмите **Emitters & music…** (эмиттеры и музыка…) в строке сцены. Диалог редактирует эмиттеры и музыку сцены; **Save** (сохранить) применяет изменения (кнопка неактивна, пока ничего не изменилось и пока у эмиттера нет звука), а **Close** (закрыть) закрывает диалог.

- **Music playlist** (плейлист музыки) выбирает плейлист или `None` (`playlist = "<id>"` в `config.toml`). При активации сцены плейлист запускается и нарастает за более долгое из двух значений: нарастание сцены или кроссфейд плейлиста. Остановка сцены переводит его в затухание. Подробности:
  - Плейлист, который уже играет при активации сцены, не перезапускается.
  - Сцена без плейлиста останавливает музыку, которую запустила предыдущая сцена, но не плейлист, запущенный вами вручную.
  - Сцена с включённым **Stop other sounds** выводит в затухание запущенный вручную плейлист, который ей не принадлежит.
  - **Stop Scene**, **Fade Out**, **STOP ALL** и соответствующие горячие клавиши завершают музыку сцены вместе со сценой.
  - О недостающем плейлисте сообщается, и музыкальный слой сцены останавливается.
- **Add emitter** (добавить эмиттер) добавляет источник случайных звуков. У каждого эмиттера есть:

| Настройка | По умолчанию | Значение |
| --- | --- | --- |
| Every … to … (интервал от … до …) | от 20 s до 60 s | Самая короткая и самая длинная пауза. Консоль допускает от 0.1 s до 1 h. Минимум выше максимума тянет за собой максимум, и наоборот. |
| Volume (громкость) | 100 % | Базовый уровень. |
| Volume jitter (разброс громкости) | 0 % | Случайный разброс уровня: `volume x (1 + jitter x u)`, `u` — случайное число от -1 до 1; результат остаётся в диапазоне от 0 до 1. |
| Pan jitter (разброс панорамы) | 0 % | Случайное положение в стерео: `jitter x u`; 0 — центр, при 100 % возможно любое положение. |
| Max overlap (максимум одновременных экземпляров) | 2 | Одновременные экземпляры этого эмиттера, от 1 до 16 в консоли. |
| Sounds (звуки) | нет | При каждом воспроизведении выбирается один звук случайно, предпочтительно тот, который сейчас не звучит. Нужен хотя бы один. |

Поведение:

- Первое воспроизведение наступает после случайного сдвига до 5 s (никогда не позже самой длинной паузы), поэтому сцена не начинается с залпа.
- Каждый эмиттер ждёт случайное время между своими двумя границами. Планировщик никогда не срабатывает чаще, чем раз в 100 ms.
- Воспроизведение длится столько же, сколько его звук (если длина неизвестна, принимается 5 s). Если в момент, когда должно начаться воспроизведение, заняты все слоты наложения, оно пропускается и выбирается новая пауза.
- Эмиттер срабатывает не более одного раза за такт, и следующая пауза отсчитывается от этого такта, поэтому зависшее приложение не выдаёт залп потом.
- Повторная активация уже работающей сцены сохраняет таймеры эмиттеров. Эмиттеры останавливаются вместе со сценой. Экземпляры, которые ещё звучат, затухают за время затухания сцены при её остановке и не затрагиваются, если та же сцена активируется снова.
- Пока сцена работает, карточка каждого эмиттера показывает живой обратный отсчёт (`Next in 12 s`, плюс `n playing`). Без работающей сцены там написано `Scene not active`, а если нет воспроизводимых звуков, — `No playable sounds`.
- Эмиттеры работают на такте Director, без отдельного потока выполнения. Движок хранит один уровень и одну панораму на звук, поэтому экземпляр, запущенный, пока тот же звук ещё играет, сохраняет панораму и уровень этого звука.

> **Примечание:** Каждый запуск сцены использует случайное начальное значение (seed); тесты фиксируют его. Воспроизведение на реальном оборудовании **(не проверено)**.

<a id="music-playlists"></a>
## Музыкальные плейлисты

Плейлист — это упорядоченный список звуков из библиотеки на шине музыки (**Music**). Он играет с панели музыки или как слой музыки сцены. Одновременно играет только один плейлист; запуск другого заменяет его.

| Настройка | По умолчанию | Значение |
| --- | --- | --- |
| Shuffle (случайный порядок) | выкл. | Каждый цикл использует каждый трек один раз, прежде чем что-либо повторится; новый цикл никогда не начинается с трека, на котором закончился предыдущий. |
| Repeat (повтор) | All | `Off` останавливается в конце (статус `Finished`). `All` перезапускает список. `One` зацикливает текущий трек без пауз. Кнопка переключает Off, All, One. |
| Crossfade | 2.0 s | `Off` (0) или до 30 s. Следующий трек начинается раньше, за `crossfade` до конца, но не дальше середины текущего, поэтому треки перекрываются. Нужна известная длина трека; не применяется при Repeat `One` и на последнем треке при Repeat `Off`. |
| Bus (`bus`) | Music | `music`, `ambience` или `sfx`. Задаётся только в `config.toml`; в консоли для этого нет элемента управления. |

Shuffle, Repeat и Crossfade сохраняются вместе с плейлистом. Изменение Shuffle или Repeat во время воспроизведения действует сразу.

На панели музыки (внизу консоли) есть **Previous track** (предыдущий трек), кнопка воспроизведения (**Play the playlist** (воспроизвести плейлист) / **Pause** (пауза) / **Resume** (продолжить), либо **Create a playlist** (создать плейлист), если плейлистов нет), **Stop the music** (остановить музыку), **Next track** (следующий трек), полоса перемотки с индикаторами времени, **Shuffle**, **Repeat Off / All / One**, название текущего трека с его позицией (`Track 3 / 12`) и кнопка **Music…**. **Previous track** перезапускает текущий трек, если он проигран дольше 3 s (или если перед ним ничего нет); иначе переходит к предыдущему треку. **Stop the music** останавливает музыку с затуханием за время кроссфейда плейлиста. Переходы **Next** и **Previous** тоже выполняются с кроссфейдом.

В менеджере **Music…** (вкладка **Playlists** (плейлисты)) **New playlist** (новый плейлист) создаёт список. В менеджере есть управление воспроизведением, остановкой, shuffle, repeat и crossfade, кнопка переименования и кнопка удаления (звуки остаются в библиотеке). В разделе **Add sounds** (добавить звуки) вы фильтруете библиотеку по названию или тегу и добавляете треки в конец кнопками **+**. Меняйте порядок треков, перетаскивая их за ручку или кнопками **Move up** (переместить вверх) и **Move down** (переместить вниз), а трек убирайте кнопкой **Remove from the playlist** (убрать из плейлиста). Удаление звука из библиотеки также убирает его из плейлистов.

- Перемотка работает, только когда трек играет или стоит на паузе и его длина известна, и никогда не попадает ближе 500 ms к концу.
- Названия берутся из метаданных файла в виде `Artist - Title` или только `Title`, затем из названия звука, затем `Unknown track`. Альбом из метаданных читается, но консоль его не показывает.
- Отсутствующие или невоспроизводимые треки пропускаются, и о них сообщается. Если ни один трек не может быть воспроизведён, плейлист останавливается и сообщает об этом. Трек, остановленный кем-то другим (не у своего конца), останавливает плейлист вместо перехода к следующему треку.
- Длинные файлы воспроизводятся с потоковым чтением с диска (см. `stream_threshold_secs`). Декодирование выполняет Symphonia с функциями Cargo (features) `vorbis`, `mp3`, `flac`, `wav` и `aac`; комментарий модуля также называет Opus, но функция декодера Opus в `Cargo.toml` не включена, поэтому воспроизведение Opus **(не проверено)**. Таблица форматов — в разделе [Звуковая библиотека](./soundboard-library.md).

<a id="timers"></a>
## Таймеры

Откройте **Timers** (таймеры) в разделе **Mix** (микширование): кнопка **Timers** стоит под **Duck** (приглушить) и **Hotkeys** (горячие клавиши), а пока таймеры работают, она показывает `Timers MM:SS` для ближайшего. Таймеры работают, только пока открыто приложение, и всегда стартуют остановленными; сохраняются только их описания.

- **Start** (запустить) взводит все включённые таймеры. После паузы **Start** показывает **Resume**.
- **Pause timers** (приостановить таймеры) замораживает отсчёт.
- **Reset** (сбросить) снимает взведение со всех таймеров. Следующий **Start** начинает отсчёт с нуля.
- В строке состояния написано `Stopped`, `Running mm:ss` или `Paused mm:ss`. В каждой строке таймера есть флажок включения, обратный отсчёт (`OFF`, `DONE`, `--:--`) и кнопки редактирования и удаления. Список **Fired** (сработавшие) внизу записывает, что было запущено, и все предупреждения.

**New timer** (новый таймер) открывает форму с полями **Name** (название; необязательно, до 60 символов; если оставить поле пустым, название генерируется), **When** (когда), **Action** (действие) и цель. **When** — это **Once, after** (однократно, через) или **Repeat every** (повторять каждые) с минутами (от 0 до 999) и секундами. Интервал должен быть не меньше 1 секунды (сам файл конфигурации принимает 100 ms). Новая форма начинается с **Once, after** 10 min и **Activate scene** (активировать сцену). Повторяющийся таймер, который опоздал, срабатывает один раз и сообщает о пропущенных периодах.

| Надпись действия | `kind` | Дополнительное поле |
| --- | --- | --- |
| Activate scene | `activate_scene` | `scene` |
| Stop scene | `stop_scene` | нет |
| Play stinger | `play_stinger` | `sound` (любой звук из библиотеки, воспроизводится один раз) |
| Stop all (fade out) (остановить всё с затуханием) | `stop_all` | `fade_ms` |
| Start playlist (запустить плейлист) | `start_playlist` | `playlist` |
| Stop music (остановить музыку) | `stop_playlist` | нет |
| Next track / Pause music (пауза музыки) / Resume music (продолжить музыку) | `next_track` / `pause_music` / `resume_music` | нет |

Таймер, который указывает на отсутствующий объект, записывает предупреждение в журнал и не влияет на остальные; его строка показывает `Cannot run: …` или строку вроде `Scene no longer exists in the library`. Отключённый таймер или таймер с некорректным описанием никогда не взводится. Редактирование таймеров во время их работы сохраняет отсчёт у тех, что не менялись.

<a id="buses-ducking-and-normalization"></a>
## Шины, приглушение и нормализация громкости

Каждый звук играет на одной шине: **Music**, **Ambience** (атмосфера) или **Sfx** (звуковые эффекты). Шина звука задаётся `bus` в его записи `[[library.sounds]]` и по умолчанию равна `ambience`; для плейлиста по умолчанию `music`. В консоли нет элемента для изменения того или другого; редактируйте `config.toml`. У каждой шины есть фейдер в разделе **Mix** (сетевая колонка). Фейдеры не сохраняются и после перезапуска возвращаются к 100 %.

**Duck** приглушает шины, перечисленные в `duck_buses` (по умолчанию Music и Ambience), пока она активна; когда она включена, на ней написано **Ducked** (приглушено). **Click** (щелчок) фиксирует приглушение до следующего щелчка. **Hold** (удержание) приглушает, только пока кнопка удерживается (нажатие короче 350 ms считается щелчком). Фиксация и удерживаемая клавиша не отменяют друг друга. Свёрнутый раздел **Duck settings** (настройки приглушения) задаёт:

| Настройка | Параметр | По умолчанию | Диапазон в консоли |
| --- | --- | --- | --- |
| Level (уровень) | `duck_amount` | `0.3` (примерно -10 dB) | от 0 до 100 % |
| Attack (атака) | `duck_attack_ms` | `200` | от 0 до 10000 ms |
| Release (восстановление) | `duck_release_ms` | `800` | от 0 до 30000 ms |
| Ducks (приглушаемые шины) | `duck_buses` | `["music", "ambience"]` | любая из трёх шин |

Приглушение (ducking) не меняет значение фейдера: после восстановления шина возвращается ровно к своему уровню фейдера. `duck_amount = 1.0` отключает приглушение, а `0.0` выключает звук приглушаемых шин. Горячие клавиши `Duck background (toggle)` и `Duck background (hold)` используют те же настройки и состояние, что и кнопка.

**NORMALIZE LOUDNESS** (нормализация громкости, normalization; `normalize`, по умолчанию выключено) измеряет звуки по EBU R128 в фоновом режиме и сохраняет поправку `gain_db` к `normalize_target_lufs` (**Target** (цель), по умолчанию `-18.0`, диапазон в консоли от -36 до -8). Измеряются загруженные звуки, у которых `gain_db` равен `0`, один раз за сеанс; измеренная поправка ограничивается диапазоном от -24 до +12 dB. Изменение цели не переписывает уже сохранённые усиления, а лишь позволяет заново измерить звуки, которые ещё не измерялись. Файлы длиннее `stream_threshold_secs` (по умолчанию 60) не измеряются. Уровень звука — это громкость, умноженная на усиление и ограниченная диапазоном от 0 до 1, поэтому положительное усиление помогает только при громкости ниже 1.0. Строка под переключателем показывает `Off: sounds keep their own level`, `On: new sounds are measured and set to -18 LUFS` или `Measuring n sounds...`. Результаты на реальных динамиках **(не проверено)**.

<a id="hotkeys"></a>
## Горячие клавиши

Откройте **Hotkeys** в разделе **Mix**. В диалоге перечислены ваши привязки (**Bindings (n)** (привязки)), и есть строка **New hotkey** (новая горячая клавиша): меню действия, второе меню цели, если действие её требует, **Capture key** (захват сочетания; нажмите **Esc**, чтобы отменить) или ввод сочетания в поле `or type: Ctrl+Shift+1` (нажмите **Enter**, чтобы принять его), а также **Add hotkey** (добавить горячую клавишу). Щёлкните клавишу в списке, чтобы её изменить. Кнопка удаления строки **Delete this hotkey** (удалить горячую клавишу) удаляет привязку. **Done** (готово) закрывает диалог. Пока редактор ждёт клавишу, ни одна привязка не срабатывает. Цифровой блок клавиатуры и клавишу Win/Super нельзя захватить; введите их вручную.

### Синтаксис клавиш

Ноль или больше клавиш-модификаторов и одна клавиша, соединённые `+`, без учёта регистра, в любом порядке. Клавиши-модификаторы: `Ctrl` (`Control`), `Alt` (`Option`), `Shift`, `Cmd` (`Command`, `Super`, `Meta`, `Win`). `CmdOrCtrl` означает `Cmd` на macOS и `Ctrl` в остальных системах. Клавиши: от `A` до `Z`, от `0` до `9`, от `F1` до `F24`, от `Numpad0` до `Numpad9` (а также `NumpadAdd`, `NumpadSubtract`, `NumpadMultiply`, `NumpadDivide`, `NumpadDecimal`, `NumpadEnter`), `Space`, `Enter`, `Escape`, `Tab`, `Backspace`, `Delete`, `Insert`, `Home`, `End`, `PageUp`, `PageDown`, стрелки `Up`, `Down`, `Left`, `Right`, а также знаки пунктуации, например `Minus`, `Comma` или `Slash`. Консоль записывает каноническую форму (`Ctrl+Alt+Shift+Cmd+Key`).

### Действия

| Надпись в меню | `kind` | Цель |
| --- | --- | --- |
| Play sound / stinger (воспроизвести звук / стингер) | `sound` | id звука |
| Activate scene | `scene` | id сцены |
| Start playlist | `playlist` | id плейлиста |
| Stop all (остановить всё) | `stop_all` | нет |
| Stop scene | `stop_scene` | нет |
| Master volume up / down (общая громкость вверх / вниз) | `master_up` / `master_down` | нет (шаг 0.05) |
| Master mute (выключить общий звук) | `master_mute` | нет |
| Duck background (toggle) (переключить приглушение фона) | `duck_toggle` | нет |
| Duck background (hold) (удерживать приглушение фона) | `duck_hold` | нет |
| Pause / resume music (пауза / продолжить музыку) | `pause_music` | нет |
| Next track | `next_track` | нет |
| Previous track | `prev_track` | нет |

Горячая клавиша звука переключает обычный звук (он запускается на собственном уровне, а второе нажатие его останавливает) и однократно запускает стингер. Master mute восстанавливает предыдущую громкость (0.8, если выключение звука пришло из другого места). Отпускание клавиши игнорируется всеми действиями, кроме `Duck background (hold)`; если отпускание потерялось (окно теряет фокус или текстовое поле забирает клавиатуру), приглушение принудительно снимается. Горячие клавиши для сцен и звуков используют текущие данные библиотеки и собственные затухания каждой сцены.

### Локальные и глобальные

- **Local** (локальные) горячие клавиши срабатывают, пока окно Bardwave имеет фокус.
- **Global** (глобальные) горячие клавиши срабатывают и в фоне. Включите их параметром `[gui] global_hotkeys = true` или флажком **GLOBAL HOTKEYS (WHEN THE WINDOW IS NOT FOCUSED)** (глобальные горячие клавиши, когда окно не в фокусе). По умолчанию выключено. В диалоге показано состояние (`Global hotkeys are off.`, `Global hotkeys active (n).` или `n could not be registered`, когда система не принимает клавишу, например потому что её занимает другая программа).
- Глобальными могут быть только сочетания с `Ctrl`, `Alt` или `Cmd`, а также клавиши `F`. Обычные клавиши, например `Space`, `A` или `Shift+1`, никогда не бывают глобальными.
- Пока в текстовом поле есть фокус, обычные клавиши и `Shift+key` вводятся в него вместо срабатывания; сочетания с `Ctrl`, `Alt` или `Cmd`, а также клавиши `F` по-прежнему срабатывают.
- Клавиши цифрового блока (`Numpad…`) окно не видит: они работают только как глобальные горячие клавиши, поэтому им нужны модификатор и включение глобальных горячих клавиш. Привязки с `Cmd` совпадают локально только на macOS (окно не видит клавишу Windows/Super).
- Клавиша, зарегистрированная глобально, доставляется и тогда, когда окно в фокусе; локальное совпадение пропускается, чтобы не срабатывать дважды.
- macOS может потребовать разрешение в «**Системные настройки > Конфиденциальность и безопасность**» («Универсальный доступ» или «Мониторинг ввода»); без него сочетания работают только при фокусе окна. Комментарии в коде говорят, что обычным клавишам разрешение не нужно, поэтому это **(не проверено)**.
- Windows: **(не проверено)**. Linux: только X11, так как Wayland не позволяет глобальные горячие клавиши. **(не проверено)**

### Конфликты и MIDI

Диалог показывает сообщение под строкой, если что-то не так. Побеждает первая из нескольких привязок с одной и той же клавишей.

| Сообщение | Значение |
| --- | --- |
| `Conflict: the same key is bound in #N, which wins - this one never fires` | Побеждает более ранняя привязка. При добавлении уже занятой клавиши предлагается **Replace** (заменить), которая заменяет эту привязку вместо добавления дубликата. |
| `Conflict: the same key is also bound in #N, which never fire` | Эта привязка побеждает перечисленные более поздние. |
| `The sound, scene or playlist it points at no longer exists` | Цель была удалена. |
| Неверный текст клавиши (например, `…has two keys…`) | Клавишу не удаётся разобрать. |

Консоль удаляет привязки, которые указывают на звук, сцену или плейлист, удалённые в ней. Горячая клавиша, которую нельзя выполнить (например, `Hotkey ignored: the audio engine is not running`), записывается в журнал, а ошибки при выполнении действия появляются в диалоге.

Привязки MIDI используют `key = "Midi:Ch1:Note60"` или `key = "Midi:CC7"` и могут быть записаны только в `config.toml`. Код для них собирается только с функцией Cargo (feature) `midi`, и даже тогда он не подключён к консоли. Консоль показывает их как `MIDI binding: MIDI input is not connected in this build, it will not fire`. Считайте MIDI недоступным **(не проверено на оборудовании)**.

<a id="configuration-reference"></a>
## Справочник по конфигурации

Сцены, плейлисты и звуки находятся в разделе `[library]`. Горячие клавиши и таймеры — на верхнем уровне. Идентификаторы — это строки UUID, которые записывает консоль. Идентификатор, написанный вручную и не являющийся UUID, заменяется при загрузке файла, а ссылки на него в сценах, эмиттерах, плейлистах и `[[hotkeys]]` переписываются; `[[timers]]` не переписываются, поэтому используйте там настоящие UUID. Значения по умолчанию: затухания сцены `2000`; сцена `curve = "equal_power"`; `stop_others = true`; элемент `volume = 1.0`, `start = "on_enter"`, `delay_ms = 0`; эмиттер `min_interval_ms = 20000`, `max_interval_ms = 60000`, `volume = 1.0`, `volume_jitter = 0`, `pan_jitter = 0`, `max_overlap = 2`; плейлист `repeat = "all"`, `crossfade_ms = 2000`, `bus = "music"`; звук `bus = "ambience"`; таймер `enabled = true`.

```toml
[gui]
global_hotkeys = false

[[library.playlists]]
id = "6a0f3b1e-52c4-4f0e-9a52-0b1f5f3a7a01"
name = "Tavern music"
items = ["2f6c1d8a-7b3e-4c52-8d61-9e0a4b7c1d02", "2f6c1d8a-7b3e-4c52-8d61-9e0a4b7c1d03"]
shuffle = true
repeat = "all"
crossfade_ms = 3000

[[library.scenes]]
id = "8c2d9e44-1f6a-4b7d-a3c5-5e7f0a9b2c04"
name = "Tavern"
fade_in_ms = 2000
fade_out_ms = 2000
curve = "linear"
stop_others = true
playlist = "6a0f3b1e-52c4-4f0e-9a52-0b1f5f3a7a01"

[[library.scenes.items]]
sound = "2f6c1d8a-7b3e-4c52-8d61-9e0a4b7c1d05"
volume = 0.4
looped = true
start = "on_enter"

[[library.scenes.emitters]]
sounds = ["2f6c1d8a-7b3e-4c52-8d61-9e0a4b7c1d06", "2f6c1d8a-7b3e-4c52-8d61-9e0a4b7c1d07"]
min_interval_ms = 20000
max_interval_ms = 60000
max_overlap = 2

[[hotkeys]]
key = "Ctrl+1"
action = { kind = "scene", target = "8c2d9e44-1f6a-4b7d-a3c5-5e7f0a9b2c04" }

[[hotkeys]]
key = "F5"
action = { kind = "stop_all" }

[[timers]]
id = "b13e5f70-3a8d-4e19-b6c2-7d4a9e0f1c08"
name = "Alarm in ten minutes"
trigger = { after_ms = 600000 }
action = { kind = "activate_scene", scene = "8c2d9e44-1f6a-4b7d-a3c5-5e7f0a9b2c04" }
enabled = true

[[timers]]
id = "c24f6a81-4b9e-4f2a-87d3-8e5bab1f2d09"
name = "Bell every half hour"
trigger = { every_ms = 1800000 }
action = { kind = "play_stinger", sound = "2f6c1d8a-7b3e-4c52-8d61-9e0a4b7c1d0a" }
enabled = true
```

Настройки звука в разделе `[audio]`: `duck_amount` (0.3), `duck_attack_ms` (200), `duck_release_ms` (800), `duck_buses` (`["music", "ambience"]`), `normalize` (false), `normalize_target_lufs` (-18.0), `stream_threshold_secs` (60, `0` выключает потоковое чтение).

> **Предупреждение:** Консоль перезаписывает `config.toml` при сохранении. Закройте Bardwave, прежде чем редактировать файл вручную.

> **Примечание:** Таймер `stop_all`, записанный без `fade_ms`, затухает за `0` ms. Значение по умолчанию для нового таймера в консоли — 2 s.

<a id="troubleshooting"></a>
## Устранение неполадок

| Симптом | Вероятная причина и решение |
| --- | --- |
| **Save Mix As Scene** неактивна | Ничего не играет. Сначала запустите звук. |
| **Stop Scene** неактивна | Нет активной сцены. |
| Горячая клавиша ничего не делает | Конфликт, удалённая цель или неверная клавиша. Прочитайте сообщение в диалоге Hotkeys и журнал. |
| Обычная клавиша работает только в окне | Обычные клавиши никогда не бывают глобальными. Добавьте модификатор. |
| Глобальные горячие клавиши ничего не делают | Опция выключена, нет разрешения или сеанс Wayland. **(не проверено)** |
| Таймер никогда не срабатывает | Таймеры не запущены или отключены. Нажмите **Start**. |
| Эмиттер молчит | Достигнут максимум одновременных экземпляров, сцена не активна или нет звуков. |
| Трек плейлиста пропускается | Файл отсутствует или не может начать воспроизведение. |
| Полоса перемотки ничего не делает | Длина трека неизвестна или ничего не играет. |
| Fade Out игнорирует ползунок | **Auto** включено. Переместите ползунок. |
| Горячая клавиша или таймер затухает за неверное время | Они используют собственные затухания каждой сцены, а не ползунок Transition. |
