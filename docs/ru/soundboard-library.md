# Звуковая библиотека

Звуковая библиотека — это панель `01 / Library` консоли. Её заголовок — **Sound Library** (звуковая библиотека), рядом выводится счётчик вида `12 Tracks`. В библиотеке хранится каждый звук, который может воспроизвести консоль, группы, к которым эти звуки относятся, их теги и настройки каждого звука (громкость, повтор, панорама). На этой странице объясняется, как добавлять звуки, упорядочивать их, исправлять отсутствующие файлы, передавать их в виде комплектов и настраивать связанные аудионастройки. Названия и значения ниже взяты из кода приложения. Некоторые надписи на экране выводятся заглавными буквами (например, `FILE NOT FOUND`, `NO MATCHES`); на этой странице используется написание из кода. Поведение, которое не проверялось на реальном оборудовании, помечено **(не проверено)**.

Библиотека сохраняется в разделе `[library]` файла `config.toml`. Добавленные звуки хранятся там, а не в самих аудиофайлах: библиотека сохраняет путь к каждому файлу. Ваши аудиофайлы библиотека никогда не меняет и не удаляет; удаление звука убирает только его запись.

<a id="adding-sounds"></a>
## Добавление звуков

В заголовке панели есть две кнопки: **Add Sound** (добавление звука) и **YouTube**. **Folder…** (папка), **Export…** (экспорт) и **Import…** (импорт) находятся в строке поиска под ними.

Звук, добавленный, когда в списке групп **Groups** (группы) выбрана группа (но не **All Sounds** (все звуки) и не **Ungrouped** (без группы)), попадает в эту группу. Это относится к **Add Sound** и к загрузкам с YouTube. Импорт папки создаёт группы сам, см. ниже.

Новый звук получает в качестве имени имя файла без расширения (у загрузки с YouTube — название видео) и громкость 100 %. Файл, который уже есть в библиотеке (с тем же путём), повторно не добавляется.

### Add Sound

Нажмите **Add Sound** (со значком «плюс») в заголовке панели. Та же кнопка показана в пустом списке. Системный диалог выбора файлов открывается с заголовком `Select Audio Files`, фильтр `Audio Files` задан как `mp3, wav, ogg, flac, opus`. Можно выбрать сразу несколько файлов. Каждый файл передаётся в аудиодвижок и появляется в списке после декодирования.

> **Примечание:** Файл, который не удаётся декодировать, не добавляется. Причина записывается в журнал (`Failed to load sound`). В интерфейсе для этого случая сообщение не показывается.

### Folder…

Нажмите **Folder…** в строке поиска. У кнопки есть подсказка `Add every sound in a folder (and its sub-folders)`.

1. Выберите папку в диалоге с заголовком `Choose a folder with sounds`.
2. Диалог **Add Folder** (добавление папки) рекурсивно сканирует папку (до 64 уровней вложенности). Элементы обходятся в отсортированном порядке: сначала файлы самой папки, затем подпапки. Сканирование только просматривает папку и ничего не меняет в библиотеке.
3. Диалог показывает ход выполнения, затем количество новых звуков (`N new sounds found`) и, если есть подпапки, список **Sub-folders** (подпапки) с количеством звуков в каждой.
4. Установите флажок **Create a group for each sub-folder** (создать группу для каждой подпапки), если нужна одна группа на каждую подпапку первого уровня (флажок по умолчанию установлен, когда найдены подпапки). Файлы на более глубоких уровнях попадают в группу своей подпапки первого уровня. Диалог перечисляет группы, которые он создаст (до 4 названий), и сколько существующих групп будет использовано повторно. Группа с таким же названием (без учёта регистра) используется повторно. Названия групп обрезаются до 32 символов. Файлы непосредственно в выбранной папке остаются без группы.
5. Нажмите **Add N Sounds** (добавить N звуков), чтобы добавить найденное. Кнопка неактивна, если ничего нового не найдено. **Cancel** (отмена) закрывает диалог без добавления.

Во время сканирования **Cancel** закрывает диалог и останавливает сканирование. Ничего не добавляется.

После добавления звуков под строкой поиска на несколько секунд появляется сообщение вида `Added 12 sounds, 2 new groups`.

Сканер пропускает:

- файлы, которые уже есть в библиотеке (по пути);
- файлы с тем же содержимым, что и другой файл или файл, уже находящийся в библиотеке (совпадают размер и хеш первых и последних 64 KiB; файлы размером до 128 KiB хешируются полностью);
- пустые файлы и сопутствующие файлы AppleDouble (`._name.mp3`);
- символические ссылки, указывающие за пределы сканируемой папки, и битые ссылки. Файлы, найденные через ссылку, обходятся последними, поэтому настоящий файл важнее ссылки на него.

Диалог сообщает, сколько файлов пропущено по каждой причине, например `3 duplicates skipped (same content as another file)`, и сколько элементов не удалось прочитать.

### YouTube

Нажмите **YouTube** в заголовке панели или в пустом списке. При узкой панели кнопка в заголовке скрывается первой. Диалог называется **Add From YouTube** (добавление с YouTube), в нём есть поле `Video or music link`. Нажмите **Add** (добавить) или Enter.

Принимаемые ссылки:

- `https://www.youtube.com/watch?v=<id>` (дополнительные параметры, например `&t=` или `&list=`, игнорируются: ссылка с `&list=` добавляет только одно видео);
- `https://youtu.be/<id>`;
- `https://music.youtube.com/watch?v=<id>` (работает любой поддомен `youtube.com`, а также `youtube-nocookie.com`);
- адреса вида `/shorts/<id>`, `/embed/<id>` и `/live/<id>`;
- только идентификатор видео из 11 символов.

Страницы плейлистов, страницы каналов и другие сайты отклоняются с сообщением `Not a YouTube video link`.

Аудио скачивается один раз с помощью yt-dlp. Файл сохраняется в папку `bardwave-library` внутри каталога данных Bardwave активного профиля, поэтому он переживает перезапуски. Загрузки конвертируются в MP3 (160K) с помощью ffmpeg. Имя файла — название видео (обрезанное до 80 символов, с заменой символов, недопустимых в Windows), за которым в скобках следует идентификатор видео. В строке показывается название без идентификатора. Видео, которое уже было загружено, повторно используется (`Already downloaded — reusing`) без сетевого трафика.

При первом использовании нужны вспомогательные инструменты. Диалог сообщает `First use downloads yt-dlp + ffmpeg once (~230 MB), then it just works`. В строках хода выполнения указаны примерно 24 MB для yt-dlp и примерно 100 MB для ffmpeg. Пока идёт загрузка, диалог показывает такие строки хода выполнения (`Connecting…`, `Downloading yt-dlp…`, `Fetching video info…`, `Downloading audio…`).

Bardwave ищет каждый инструмент сначала рядом с исполняемым файлом, затем в `PATH`, затем в собственной папке `tools` (в корневом каталоге данных, общем для всех профилей). Копия, установленная вами, используется раньше загруженной.

| Инструмент | Когда загружается | Если его нет |
|---|---|---|
| yt-dlp | При первом использовании, около 24 MB, из релиза на GitHub | Загружается автоматически в Windows, macOS и Linux (x86-64 и ARM64). Не проверено на macOS и Linux. В других системах выводится сообщение с просьбой установить его вручную |
| ffmpeg | При первом использовании, около 100 MB (сборка для Windows) | Загружается автоматически только в Windows. В других системах загрузка прерывается с сообщением `ffmpeg not found on this system.` Установите его сами, например командой `brew install ffmpeg` или `apt install ffmpeg` |

Ошибки yt-dlp (удалённое видео, региональная блокировка, отсутствие сети) показываются в диалоге.

> **Примечание:** Одновременно выполняется только одна загрузка с YouTube. **Close** (закрыть), которая показывается вместо **Cancel** во время загрузки, и Esc её не отменяют: диалог закрывается, загрузка продолжается в фоне, а звук появляется по её завершении. Пока загрузка идёт, кнопка **YouTube** не работает. Если загрузка завершится ошибкой после закрытия диалога, ошибка только записывается в журнал.

<a id="supported-formats"></a>
## Поддерживаемые форматы

Файлы декодируются с помощью Symphonia. В сборке включены функции Cargo (feature) `vorbis`, `mp3`, `flac`, `wav` и `aac` (`Cargo.toml`). Декодированный звук преобразуется в стерео 48 kHz (моно дублируется в оба канала, многоканальные файлы сводятся к двум).

| Расширение | Статус | Примечания |
|---|---|---|
| `.wav` | Поддерживается | Add Sound, сканирование папки, Locate (указать файл заново), комплекты |
| `.mp3` | Поддерживается | Add Sound, сканирование папки, Locate, комплекты |
| `.ogg` | Поддерживается | Vorbis. Add Sound, сканирование папки, Locate, комплекты |
| `.flac` | Поддерживается | Add Sound, сканирование папки, Locate, комплекты |
| `.aac` | Указан | Принимается сканированием папки, Locate и комплектами, но не предлагается фильтром Add Sound. Воспроизведение не проверено |
| `.m4a` | Указан | Принимается сканированием папки, Locate и комплектами, но не предлагается фильтром Add Sound. Контейнер MP4 в сборке не включён, поэтому воспроизведение не проверено |
| `.opus` | Не проверено | Предлагается фильтром Add Sound, но не принимается сканированием папки, Locate или комплектами, а декодер Opus не включён. Считайте формат неподдерживаемым |

Сканирование папки, **Locate…** и импорт комплекта используют одну и ту же проверку расширения (без учёта регистра), кроме `.opus`, который есть только в фильтре Add Sound. Если **Locate…** получает файл с другим расширением, появляется сообщение `That file is not a supported audio file`.

<a id="per-sound-settings"></a>
## Настройки отдельного звука

В строке каждого звука есть следующие элементы управления слева направо. Строка также показывает название, строку вида `48 kHz / 00:42 / WAV` (на узкой строке она скрывается первой) и теги.

| Элемент | Как использовать | Диапазон | По умолчанию | Хранится как |
|---|---|---|---|---|
| Кнопка воспроизвести / остановить | Нажмите круглую кнопку слева | — | — | — |
| Повтор | Нажмите квадратный значок. Подсказка: `Repeat: on` или `Repeat: off`. Вступает в силу сразу, в том числе для звучащего звука | on / off | off | `looped` |
| Предпрослушивание (preview) | Значок наушников. См. [Предпрослушивание в наушниках](#headphone-preview) | — | — | не сохраняется |
| Громкость | Нажмите или перетащите ползунок в строке. Рядом выводится процент | от 0 % до 100 % | 100 % | `volume` (от 0.0 до 1.0) |
| Группа | Нажмите название группы в строке. Подсказка: `Change group` | — | Без группы | `group` |
| Убрать | Нажмите значок ✕ | — | — | удаляет звук |

Ползунок и название группы скрываются в очень узких строках. Наведите курсор на строку, чтобы увидеть её полное название, путь и группу. Строки выводятся в порядке загрузки звуков; звуки, у которых отсутствует файл и которые не загружены, идут последними.

**Remove** (убрать, значок ✕) в строке сразу удаляет звук из библиотеки без подтверждения. Звук также убирается из всех сцен, эмиттеров (источников случайных звуков), плейлистов и горячих клавиш, которые его используют. Аудиофайл на диске не затрагивается.

### Pan

Панорама (pan) задаётся в меню, которое открывается щелчком правой кнопки мыши по строке, в блоке **Pan**.

- Ползунок идёт от `L 100%` до `R 100%`. В центре он показывает `Centre`. Значения, очень близкие к центру (менее 5 %), притягиваются к центру.
- Дважды щёлкните ползунок или нажмите Home, когда он в фокусе, чтобы вернуть его в центр.
- С клавиатуры стрелки перемещают ползунок с шагом 5 %. Удерживайте Shift, чтобы шаг был 25 %.
- Перемещение ползунка сразу меняет звук, в том числе во время воспроизведения.
- Панорама в центре не записывается в файл конфигурации.

### Стингеры и сцены

В том же контекстном меню есть пункты **Use As Stinger** (сделать стингером), **Remove Stinger Flag** (снять флаг стингера) и **Add to scene** (добавить в сцену). Стингер (stinger) — однократный звук, который воспроизводится поверх сцены. Он не останавливает другие звуки и получает пэд на панели сцен. Сцены выходят за рамки этой страницы.

> **Примечание:** Шина (bus) микшера для звука (`bus`: `music`, `ambience` или `sfx`) — это настройка в файле конфигурации. Я не нашёл элемента управления для неё ни в строке звука, ни в его меню (не проверено).

<a id="groups"></a>
## Группы

Группы — это категории библиотеки. Они перечислены в списке групп **Groups** слева на панели.

- **All Sounds** показывает все звуки с их общим количеством.
- **Ungrouped** показывает звуки без группы.
- Группы идут под надписью **Categories** (категории). Каждая группа показывает количество своих звуков. Счётчики следуют за текущим поиском и фильтром по тегам.
- Нажмите значок **+** в заголовке списка групп (подсказка `New group`), чтобы создать группу. Новая группа становится выбранной.
- Наведите курсор на группу, чтобы вместо её счётчика появились значок редактирования (подсказка `Rename group`) и значок ✕ (подсказка `Delete group`).

Пробелы по краям названий групп удаляются, названия ограничены 32 символами и должны быть уникальными без учёта регистра. В диалогах выводится `Up to 32 characters`. Если название не принимается, показывается одно из сообщений: `Enter a group name`, `Maximum 32 characters` или `A group with this name already exists`.

| Действие | Диалог | Кнопка | Действие |
|---|---|---|---|
| Создание | **New Group** (новая группа) | **Create** (создать) | Добавляет пустую группу |
| Переименование | **Rename Group** (переименовать группу) | **Save** (сохранить) | Звуки остаются на своих местах |
| Удаление | **Delete Group** (удалить группу) | **Delete** (удалить) или **Keep** (оставить), чтобы отказаться | Звуки не удаляются. Они остаются в библиотеке и становятся без группы. Подзаголовок `This cannot be undone` относится к группе |

Чтобы переместить звук в другую группу, нажмите название группы в его строке. Диалог **Move Sound** (переместить звук) со строкой `Assign to` перечисляет `Ungrouped` и все группы. Нажмите одну из них, чтобы назначить ей звук. Если групп нет, диалог показывает `No groups yet`.

Когда окно узкое, список групп сужается и может быть скрыт. Строки продолжают работать.

<a id="tags-and-search"></a>
## Теги и поиск

В поле поиска выводится подсказка `Search name or tag…`. Рядом с текстом появляется кнопка со значком (подсказка `Clear search`).

- Поисковый запрос совпадает (как часть текста) с названием звука, именем его файла или любым из его тегов.
- Сравнение не зависит от регистра для всех букв Unicode. Диакритические знаки не игнорируются: `echo` не находит `écho`.
- Несколько слов должны совпасть все сразу (AND).
- Поиск работает внутри выбранной группы.

Теги показываются в виде плашек тегов под строкой поиска. Каждая плашка показывает количество звуков с этим тегом при текущем фильтре. Нажмите плашку, чтобы добавить её в фильтр; нажмите ещё раз, чтобы снять выбор. Звуки должны иметь все выбранные теги. Сначала идут выбранные плашки, затем самые частые теги. Показывается не более 14 плашек, после них выводится `+N more tags`.

Когда фильтр активен, появляется строка `Showing N of M sounds` (M — вся библиотека). **Clear** (очистить) убирает поиск и выбор тегов. Если ничего не подходит, панель показывает `NO MATCHES` и **Clear Filters** (сбросить фильтры).

### Редактирование тегов

Нажмите текст тегов в строке (подсказка `Edit tags`; в строке показывается до четырёх тегов в виде `#tag`, а затем `+N`). В строке без тегов наведите курсор, чтобы появилась надпись `+ TAG`. Строка, помеченная `File not found`, вместо этого показывает `LOCATE…`. Диалог **Edit Tags** (редактирование тегов) содержит:

- `Tags on this sound` с кнопкой `Remove this tag` у каждого тега;
- `Add tags (separate with commas)` с кнопкой **Add** (добавить; Enter тоже работает);
- `Already used` с подсказками до 8 существующих тегов, которые совпадают с вводимым текстом и которых у звука ещё нет;
- **Done** (готово).

Пробелы по краям тегов удаляются, теги хранятся в нижнем регистре, ограничены 32 символами и не дублируются. Тег длиннее 32 символов отклоняется с сообщением `"…" is too long (at most 32 characters)`, и из этого ввода ничего не добавляется.

<a id="missing-files"></a>
## Отсутствующие файлы

Звук, файл которого пропал, остаётся в библиотеке. В его строке показываются янтарный значок `File not found`, янтарная рамка и ссылка `LOCATE…` (подсказка `Pick the file's new location`). Звук, который вообще не удалось загрузить, показывается более короткой строкой с тем же значком, путём и кнопкой **Locate…**. Звук сохраняет все свои ссылки в сценах, плейлистах и горячих клавишах.

Над списком янтарный баннер показывает `N files not found` и две кнопки:

- **Replace Path Prefix…** (заменить префикс пути) — используйте, когда переехала целая папка;
- **Recheck** (повторная проверка; подсказка `Look for the files again`).

Библиотека также в фоновом режиме проверяет наличие файлов примерно каждые 20 секунд. Файл считается присутствующим, если по сохранённому пути есть файл.

> **Примечание:** Проверка обновляет только признаки отсутствия файла. Звук, который не удалось загрузить при запуске, потому что диск был не подключён, загружается снова после **Locate…**, **Replace Path Prefix…** или импорта комплекта, либо при перезапуске Bardwave. Вернёт ли такой звук одна только **Recheck** после подключения диска, не проверено; код запрашивает перезагрузку только после этих трёх действий.

### Locate

Нажмите **Locate…** в строке или ссылку `LOCATE…`. Диалог выбора имеет заголовок `Locate the sound file` и открывается в ближайшей папке выше старого пути, которая ещё существует. Выбранный файл заменяет старый путь (`Relinked "name"`). Звук сохраняет свой идентификатор, поэтому сцены и горячие клавиши продолжают работать. Если новый файл уже используется другим звуком, библиотека отказывает с сообщением `That file is already used by another sound in the library`.

### Remove

Значок ✕ в строке отсутствующего файла (подсказка `Remove from the library`) удаляет звук. Он также убирает звук из сцен, эмиттеров, плейлистов и горячих клавиш и сообщает, сколько ссылок удалено.

### Replace Path Prefix

Используйте это, когда переехала вся папка со звуками, например с `/Volumes/Old/Sounds` на `/Volumes/New/Sounds`.

1. Нажмите **Replace Path Prefix…**. Старое начало пути заполняется автоматически папкой, общей для отсутствующих файлов.
2. Проверьте или введите старое начало пути в поле **Old start of the path** (старое начало пути).
3. Введите новое начало пути в поле **New start of the path** (новое начало пути). Рядом с этим полем используйте **Browse…** (обзор), чтобы выбрать новую папку.
4. Диалог показывает, сколько путей изменится (`N paths will change`), сколько из них сейчас не найдено, и до трёх примеров. Если ничего не совпадает, выводится `No sound path starts with that prefix.`, а **Replace** (заменить) неактивна.
5. Нажмите **Replace**. Появляется сообщение `Rewrote N paths`, и файлы проверяются снова.

Сопоставление работает по целым компонентам пути, поэтому `/music` не совпадает с `/music2/a.wav`. Оба разделителя `/` и `\` принимаются, и разделители преобразуются, когда два префикса записаны в разных стилях. Пути переписываются, даже если файлов по новому месту нет. Замена, из-за которой два звука получили бы один путь, пропускается.

<a id="bundles"></a>
## Комплекты

Комплект — это файл `.zip`, который переносит набор звуков в другую установку Bardwave. Он содержит `bundle.toml` и, по желанию, аудиофайлы в папке `audio/`.

### Что входит в комплект

| Входит | Не входит |
|---|---|
| Группы | Горячие клавиши |
| Звуки: название, группа, громкость, повтор, теги, усиление, шина, флаг стингера, панорама | Настройки аудиоустройств (устройства вывода и предпрослушивания) |
| Сцены и плейлисты | Настройки нормализации громкости (normalization) и приглушения (ducking) |
| Аудиофайлы, только если установлен флажок **Include the audio files** (включить аудиофайлы) | Профили |

Экспорт всегда охватывает всю библиотеку, а не только звуки, которые вы видите при фильтре. Комплект без аудио показывает свои звуки как `File not found`, пока вы не укажете файлы.

Звуки записываются по пути относительно папки, которая общая для всех экспортируемых звуков (так `~/Music/Tavern/a.ogg` и `~/Music/Fx/b.wav` становятся `Tavern/a.ogg` и `Fx/b.wav`). Если у звуков нет общей папки, сохраняются только имена файлов. Символы, недопустимые в некоторых системах, заменяются.

Пример минимального манифеста (`bundle.toml`):

```toml
format = "bardwave-bundle"
version = 1
name = "Tavern pack"

[[groups]]
id = "3f1c9a52-0d5e-4b8e-9a61-2c7d8e9f0a11"
name = "Tavern"

[[sounds]]
id = "8b2e4d10-7a3c-4f5e-b6d9-1e2f3a4b5c6d"
name = "Crowd"
rel_path = "Tavern/crowd.ogg"
audio = true
volume = 0.8
looped = true
group = "3f1c9a52-0d5e-4b8e-9a61-2c7d8e9f0a11"
tags = ["tavern"]
```

### Export

1. Нажмите **Export…** в строке поиска (подсказка `Save the library as a shareable .zip bundle`).
2. В диалоге **Export Bundle** (экспорт комплекта) задайте **Bundle name** (название комплекта), по умолчанию `Bardwave set`.
3. Оставьте флажок **Include the audio files** установленным, чтобы включить аудио, или снимите его, чтобы получить небольшой комплект, содержащий только данные библиотеки.
4. Нажмите **Choose File & Export…** (выбрать файл и экспортировать). Диалог сохранения предлагает `<name>.zip`; расширение `.zip` добавляется, если вы его не указали. Кнопка неактивна, когда библиотека пуста.
5. Во время работы используйте **Cancel Export** (отменить экспорт) — Esc его не останавливает. Отменённый экспорт ничего не записывает и возвращает к параметрам. По завершении диалог сообщает количество экспортированных звуков и аудиофайлов с их размером. Нажмите **Done**.

Звук, файл которого отсутствует, экспортируется без аудио, и диалог предупреждает об этом до и после экспорта. Архив записывается во временный файл рядом с целевым путём и переименовывается по завершении, поэтому неудачный экспорт никогда не оставляет повреждённый комплект. Существующий файл с тем же именем заменяется.

### Import

1. Нажмите **Import…** и выберите `.zip` в диалоге с заголовком `Choose a bundle to import`.
2. Диалог **Import Bundle** (импорт комплекта) проверяет комплект. Он показывает название комплекта, количество элементов (`N sounds, N groups, N scenes, N playlists`, с версией Bardwave, которой он создан) и то, есть ли внутри аудио (`N audio files inside`, с размером) или нет.
3. Выберите, что делать с существующими элементами, в разделе **If something already exists** (если что-то уже существует):

| Вариант | Правило | Поведение |
|---|---|---|
| **Keep mine** (оставить мои) | пропустить (по умолчанию) | Ваши существующие элементы сохраняются. Копии из комплекта не импортируются, а сцены и плейлисты из комплекта ссылаются на ваши элементы. Звук, единственный конфликт которого — существующий файл в целевой папке, регистрируется для этого файла, который не перезаписывается |
| **Keep both** (оставить оба) | переименовать | Импортированной копии присваивается свободное имя, например `Tavern (2)` (файл становится `hit (2).wav`), и новый идентификатор, если его идентификатор занят. Повторный импорт того же комплекта создаёт копии |
| **Use the bundle's** (использовать из комплекта) | заменить | Содержимое комплекта заменяет ваше. Элемент сохраняет свой идентификатор, поэтому горячие клавиши и сцены остаются действительными. Существующие аудиофайлы в целевой папке перезаписываются |

4. Задайте **Sound files go to** (папка для файлов звуков) или нажмите **Browse…** (диалог выбора имеет заголовок `Choose the folder for the sounds`). По умолчанию папка — `bardwave-library/imported/<bundle name>` внутри каталога данных.
5. Диалог показывает **This import would** (этот импорт выполнит): новые, переименованные, заменённые и пропущенные элементы, а также аудиофайлы для записи. Это пробный прогон: он ничего не меняет. Он обновляется при смене правила и при выходе из поля папки.
6. Нажмите **Import** (кнопка неактивна, пока поле папки пусто или пробный прогон выдаёт ошибку). **Cancel Import** (отменить импорт) доступна, пока импорт выполняется. В конце нажмите **Done**. Под строкой поиска появляется сообщение `Bundle imported`.

Элементы конфликтуют, если у них совпадает идентификатор, или если у группы, сцены или плейлиста совпадает название (без учёта регистра), или если у звука совпадает путь, либо, для звука с аудио, целевой файл уже существует.

Библиотека меняется только после записи всех файлов. Если импорт завершился ошибкой или был отменён, созданные им файлы удаляются. Файл, перезаписанный при варианте **Use the bundle's**, восстановить нельзя.

> **Предупреждение:** **Use the bundle's** перезаписывает существующие аудиофайлы в целевой папке. Сначала сделайте резервную копию этой папки, если её файлы для вас важны.

### Ограничения безопасности

Комплекты могут прийти от кого угодно, поэтому импортёр считает их недоверенными.

- Элемент с абсолютным путём, `..` или `.`, пустой частью, обратной косой чертой, двоеточием, управляющим символом или символической ссылкой отклоняет весь архив. Та же строгая проверка применяется к путям звуков, записанным внутри `bundle.toml`. Сообщение начинается с `Import blocked for safety`, и ничего не изменяется.
- Файлы звуков записываются только внутри целевой папки (проверяется и реальное расположение каждой папки). Записываются только файлы `wav`, `flac`, `mp3`, `ogg`, `m4a` и `aac`. Другие файлы пропускаются с предупреждением, а звук импортируется без аудио.
- Ограничения размера проверяются по заявленным размерам и по фактически прочитанным байтам. Комплект, превышающий ограничение, отклоняется с тем же сообщением `Import blocked for safety`:

| Ограничение | По умолчанию |
|---|---|
| Элементов в архиве | 20 000 |
| Групп, звуков, сцен и плейлистов вместе | 100 000 |
| Несжатый `bundle.toml` | 16 MiB |
| Несжатый размер одного аудиофайла | 2 GiB |
| Общий несжатый размер | 8 GiB |

Панель использует эти значения по умолчанию. Они не задаются в интерфейсе.

Zip-архив без `bundle.toml` отклоняется с сообщением `This zip is not a Bardwave bundle`. Комплект более новой версии формата отклоняется с просьбой обновить Bardwave.

<a id="headphone-preview"></a>
## Предпрослушивание в наушниках

В каждой строке есть кнопка с наушниками. Нажмите её, чтобы воспроизвести звук только на этом компьютере. Игроки его не слышат. Нажмите её ещё раз, чтобы остановить. Нажатие кнопки другого звука переключает предпрослушивание на этот звук.

- Подсказка: `Preview in your headphones (players do not hear it)`.
- Для отсутствующих файлов кнопка недоступна. Её подсказка: `Preview is not available for this sound`.
- На активном предпрослушивании подсказка: `Stop preview`.
- Предпрослушивание проигрывается один раз (без повтора), с громкостью звука, включая усиление нормализации громкости. Оно игнорирует панораму и шину звука.
- **Stop All** (остановить всё) тоже останавливает предпрослушивание, как и другие пути остановки всего (горячая клавиша, таймер, удалённое управление).
- Если основной вывод звука не запущен, сообщение говорит, что предпрослушивание воспроизводится только на этом компьютере, и называет состояние вывода.

Вывод предпрослушивания задаётся в разделе **AUDIO OUTPUT** (вывод звука) правой колонки, в выпадающем списке **Preview**. Значение по умолчанию — `Same as output`. В конфигурации параметр — `preview_device` в `[audio]`. Предпрослушивания никогда не попадают в аудиопоток (stream) игроков.

> **Примечание:** Маршрутизация предпрослушиваний на отдельную звуковую карту не проверена на реальном оборудовании.

<a id="loudness-normalization"></a>
## Нормализация громкости

Нормализация один раз измеряет каждый звук по EBU R128 и сохраняет фиксированное усиление, которое приводит его к целевой громкости. По умолчанию она выключена, поэтому существующие библиотеки звучат как раньше.

Включите её в разделе **MIX** (микширование) правой колонки (вместе с элементами управления сетью) флажком **NORMALIZE LOUDNESS** (нормализация громкости). Поле **Target** (целевая громкость) задаёт цель в LUFS; оно принимает значения от -36 до -8 LUFS.

Строка состояния показывает одно из:

- `Off: sounds keep their own level`
- `On: new sounds are measured and set to -18 LUFS` (число — ваша целевая громкость)
- `Measuring N sounds...`

Как это работает:

- Интегральная громкость и истинный пик измеряются по декодированному аудио в фоновом потоке. Звуки короче 400 ms и беззвучные звуки не измеряются.
- Усиление ограничено диапазоном от -24 dB до +12 dB. Повышение ограничено так, чтобы истинный пик оставался ниже -1 dBTP.
- Усиление сохраняется в библиотеке как `gain_db`. Уровень звука равен `volume × 10^(gain_db / 20)`, но не выше 1.0. Ваша настройка громкости не перезаписывается.
- Поскольку уровень ограничен 1.0, положительное усиление слышно только тогда, когда громкость ниже 1.0. Большинству громких материалов нужно отрицательное усиление.
- Когда нормализация включена, измеряется каждый загруженный звук, у которого ещё нет усиления (`gain_db = 0.0`), и каждый звук, который вы добавите позже. Звук, у которого усиление уже сохранено, повторно не измеряется.
- Изменение цели не измеряет заново звуки, у которых уже есть усиление. Чтобы измерить такой звук заново, верните его `gain_db` к `0.0` в `config.toml` и перезапустите приложение (не проверено).
- Выключение нормализации сохраняет уже записанные усиления, и они продолжают применяться.
- Файлы с потоковым чтением (см. ниже) не измеряются.

<a id="streaming-long-files"></a>
## Потоковое чтение длинных файлов с диска

Файл длиннее `stream_threshold_secs` (по умолчанию 60 секунд) не загружается в память. Он декодируется в фоновом потоке и воспроизводится из кольцевого буфера примерно на 3 секунды. Это удерживает расход памяти низким: один час стереозвука занимал бы в памяти около 1.4 GB.

- Короткие файлы остаются в памяти, поэтому запускаются мгновенно.
- Если фоновый поток отстаёт, на отсутствующем участке воспроизводится тишина и фиксируется опустошение буфера (underrun). Поток воспроизведения звука не останавливается.
- Повтор работает и с файлами, которые читаются потоково. Источник потокового чтения также поддерживает перемотку, но в строках библиотеки нет элемента управления перемоткой.
- Предпрослушивание в наушниках работает с файлами, которые читаются потоково.
- Установите `stream_threshold_secs = 0`, чтобы отключить потоковое чтение.

Если длительность не известна из заголовка файла (у некоторых MP3-файлов), решает размер файла: файл, больший примерно 16 kB на секунду порога, читается потоково.

<a id="configuration-reference"></a>
## Справочник по конфигурации

Данные библиотеки хранятся в разделах `[[library.groups]]` и `[[library.sounds]]`. Аудионастройки находятся в разделе `[audio]`. Значения ниже — значения по умолчанию из кода. Для всех остальных параметров см. [справочник по конфигурации](./configuration.md).

```toml
[audio]
normalize = false              # measure sounds without a gain_db and store one
normalize_target_lufs = -18.0  # target loudness, in LUFS
stream_threshold_secs = 60     # longer files are streamed; 0 = never
# preview_device = "Headphones"  # absent = previews use the main output

[[library.groups]]
id = "3f1c9a52-0d5e-4b8e-9a61-2c7d8e9f0a11"
name = "Tavern"

[[library.sounds]]
id = "8b2e4d10-7a3c-4f5e-b6d9-1e2f3a4b5c6d"
path = "/Users/me/Music/Tavern/crowd.ogg"
name = "Crowd"
volume = 0.8                   # 0.0 to 1.0
looped = true
group = "3f1c9a52-0d5e-4b8e-9a61-2c7d8e9f0a11"
tags = ["tavern", "crowd"]
pan = -0.25                    # -1.0 (left) to 1.0 (right)
gain_db = 0.0                  # written by normalization
bus = "ambience"               # "music", "ambience" or "sfx"
oneshot_stinger = false
```

| Параметр | Раздел | По умолчанию | Диапазон или значение |
|---|---|---|---|
| `normalize` | `[audio]` | `false` | Включает нормализацию громкости |
| `normalize_target_lufs` | `[audio]` | `-18.0` | Целевая громкость. Поле **Target** принимает значения от -36 до -8 LUFS |
| `stream_threshold_secs` | `[audio]` | `60` | Секунды; `0` отключает потоковое чтение |
| `preview_device` | `[audio]` | отсутствует | Имя устройства для предпрослушивания. Если параметр отсутствует, используется основной вывод |
| `id` | `[[library.sounds]]` | генерируется | Постоянный идентификатор. Генерируется, если отсутствует |
| `path` | `[[library.sounds]]` | обязательный | Путь к аудиофайлу |
| `name` | `[[library.sounds]]` | имя файла | Отображаемое название. Если пусто, используется имя файла |
| `volume` | `[[library.sounds]]` | `1.0` | от `0.0` до `1.0` |
| `looped` | `[[library.sounds]]` | `false` | Повтор |
| `group` | `[[library.sounds]]` | отсутствует | Идентификатор группы |
| `tags` | `[[library.sounds]]` | `[]` | Нижний регистр, до 32 символов |
| `pan` | `[[library.sounds]]` | `0.0` | от `-1.0` до `1.0`; не записывается, когда в центре |
| `gain_db` | `[[library.sounds]]` | `0.0` | Записывается нормализацией. При загрузке библиотеки значения ограничиваются диапазоном от -48 до +24 dB |
| `bus` | `[[library.sounds]]` | `"ambience"` | `"music"`, `"ambience"` или `"sfx"` |
| `oneshot_stinger` | `[[library.sounds]]` | `false` | Воспроизводится как однократный звук поверх сцены, не останавливая другие звуки |

Значения `pan` и `volume` на уровне звука записывает интерфейс. Файл конфигурации служит только хранилищем; меняйте эти значения на панели.

Про удалённый доступ к странице игроков см. [HTTPS (защищённое соединение)](./https.md). Подробнее о проблемах загрузки с YouTube, отсутствующих файлах и безопасности импорта комплектов см. в разделе [Устранение неполадок, FAQ и безопасность](./troubleshooting-security.md).

<a id="troubleshooting"></a>
## Устранение неполадок

| Симптом | Вероятная причина | Что делать |
|---|---|---|
| Янтарный баннер `N files not found` | Файлы перемещены или диск не подключён | Подключите диск и перезапустите Bardwave (см. примечание в разделе [Отсутствующие файлы](#missing-files)). Для перемещённой папки используйте **Replace Path Prefix…**. Для отдельных файлов нажмите **Locate…** |
| Звук показывает `File not found` сразу после импорта | В комплекте не было аудио | Нажмите **Locate…** в каждой строке или импортируйте комплект, экспортированный с аудио |
| `Not a YouTube video link` | Страница плейлиста, канал или другой сайт | Вставьте ссылку на одно видео |
| `ffmpeg not found on this system.` (macOS, Linux) | ffmpeg не установлен | Установите ffmpeg через менеджер пакетов и повторите попытку |
| Загрузка с YouTube при первом запуске идёт медленно | Загружаются yt-dlp и ffmpeg | Подождите. Последующие загрузки используют уже загруженные инструменты |
| Кнопка **YouTube** не реагирует | Загрузка ещё идёт (одновременно только одна) | Дождитесь её завершения |
| Файл добавлен, но строка не появилась | Декодер не смог прочитать файл (например, `.opus` или `.m4a`) | Найдите `Failed to load sound` в журнале. Преобразуйте файл в WAV, FLAC, MP3 или OGG |
| `That file is not a supported audio file` | Неверное расширение | Выберите файл с поддерживаемым расширением |
| `That file is already used by another sound in the library` | Выбранный файл относится к другой записи | Сначала уберите дублирующую запись |
| `No sound path starts with that prefix.` | Старый префикс не совпадает с сохранёнными путями | Скопируйте точное начало пути из подсказки звука |
| `Import blocked for safety` | Архив содержит небезопасный элемент или превышает ограничения по размеру | Не импортируйте его. Попросите отправителя прислать новый экспорт |
| Предпрослушивание недоступно | Файл отсутствует | Сначала укажите файл |
| Нормализация не меняет длинный файл | Файл читается потоково, поэтому он не измеряется | Увеличьте `stream_threshold_secs`, если файл нужно измерить |
| Усиленный звук не становится громче | Уровень ограничен 1.0 | Сначала уменьшите громкость или примите отрицательное усиление |
| `NO MATCHES` | Поиск или фильтр по тегам исключает всё | Нажмите **Clear Filters** |
